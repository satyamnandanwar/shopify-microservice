# Spring Boot Microservices Project

This project demonstrates a microservices-based architecture built using Java and Spring Boot.

## Tech Stack
- Java
- Spring Boot
- Spring Cloud
- MySQL
- JPA / Hibernate
- REST APIs

## Services
- Product Service
- Cart Service
- Order Service
- Payment Service

## Features
- RESTful API communication
- Service-to-service interaction
- Database integration
- Scalable backend design

## Purpose
This project is built to understand and implement real-world backend architecture using microservices.
